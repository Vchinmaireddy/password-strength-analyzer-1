Password Strength Analyzer

A simple and interactive Password Strength Analyzer built to evaluate the security level of passwords based on multiple criteria such as length, uppercase/lowercase letters, numbers, and special characters.

Features
Checks password strength in real-time
Detects:
Minimum length
Uppercase letters
Lowercase letters
Numbers
Special characters
Displays strength levels:
Weak
Medium
Strong
User-friendly interface
Lightweight and fast

Installation
Clone the repository:
git clone https://github.com/your-username/password-strength-analyzer.git
Navigate to the project folder:
cd password-strength-analyzer
Open index.html in your browser.
How It Works

The analyzer evaluates passwords based on:

Password length
Presence of uppercase characters
Presence of lowercase characters
Numbers included
Special symbols used

The more conditions satisfied, the stronger the password becomes.
